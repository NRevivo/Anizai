# C_cloud/plans/

Future Domain-C deployment plans (e.g. an `anizai-agent` cloud rebuild) land here
when a specific deployment is actively planned; until then, pending cloud work lives
as backlog rows in `cloud_sprints.md §2`.

A backlog item graduates into a plan file here only when Ron decides to do a specific
deployment.

re-platform. It is a **pointer only**: the plan itself is not version-controlled and lives
